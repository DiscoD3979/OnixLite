**Onix Lite** - открытая версия клиента Onix для Mindustry.

Полная версия Onix закрыта и доступна только для друзей. Lite - это то же самое ядро
(те же функции автоматизации, тот же интерфейс), но:

- **без** закрытых фич полной версии;

## Что в 3.4.5

- **Поиск функций** в панели: раскладка йцукен/qwerty, транслит, опечатки, поиск по названию.
- **Панель функций**: вылет из-под низа экрана, каскад категорий, плавное появление строк.
- **Раздел «Анимации»**: выключалка всех анимаций и каждой по отдельности.
- **Таб игроков**: плавное появление, каскад игроков, плавный скролл.
- **Чат**: сообщения вылетают снизу вверх, «печатная машинка», плавная каретка.
- **Кнопки голосования** в чате: отдельной строкой под сообщением, с рамкой.
- **HUD активных функций** с градиентом и «кастом цветом».
- **Единая загрузка**: свой сплэш, фиолетовая полоса со свечением и сияющая звезда —
  и при загрузке ассетов, и при входе на любой сервер и в мир.
- **Звёздочка** на загрузочном экране со свечением.

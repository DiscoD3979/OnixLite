**Onix Lite** — открытая версия клиента Onix для Mindustry: то же ядро автоматизации
и тот же интерфейс, но без закрытых фич.

## Возможности

- Панель функций с поиском (раскладки, транслит, опечатки) и большим числом настроек
- Автоматизация: выброс, стрельба, Авто-ответчик, авто-поли, авто-майнер
- Бот: Антигриф бот или Ассист бот (с предугадыванием действий игроков)
- Таб игроков: спектать, мут, статистика там же включаются Боты, фан функция метки на курсор игрока
- Чат: плавные сообщения, плавный скролл, кнопки голосования. vote n / vote y
- HUD активных функций, «кастом цвет», радуга, все можно размещать редактировать изменять.
- Свой загрузочный экран: сплэш, фиолетовая полоса со свечением и сияющая звезда
- Свой апдейтер: новая сборка прилетает сама
- Гибкие настройки некоторых функций
- Многое другое что нельзя описать)

## Управление

1. Правый shift — открыть панель
2. Z — передвигать ботом
3. Калькулятор — CTRL + ПКМ

## Установка

1. Скачай `Onix-Lite.jar` из [релизов](https://github.com/DiscoD3979/OnixLite/releases)
2. Запусти jar — Mindustry подтянется сам
